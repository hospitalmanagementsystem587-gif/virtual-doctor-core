Virtual Doctor Core SDK

Hospital Website & Portal Embed Demo

This page demonstrates how easily the Virtual Doctor Copilot embeds into any existing hospital website (such as sastahospital.in, a patient portal, or an emergency triage kiosk).

Embed Code Snippet

<!-- 1. Include the Virtual Doctor Widget Script -->
<script src="https://your-virtual-doctor.onrender.com/widget/virtual-doctor.js"></script>

<!-- 2. Initialize the Copilot -->
<script>
  window.addEventListener('DOMContentLoaded', () => {
    new VirtualDoctorWidget({
      apiBase: "http://localhost:8010",
      hospitalName: "Vedant Hospital & Research Center",
      themeColor: "#53172a"
    });
  });
</script>
